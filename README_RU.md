# TrendRadar (русское описание)

Этот репозиторий — форк `sansan0/TrendRadar` и используется как эталонный benchmark для:
- мониторинга трендов и инфоповодов из множества источников,
- фильтрации по ключевым словам,
- автоматической доставки уведомлений,
- AI-аналитики и подготовки кратких сводок.

## Зачем этот форк
- Сравнение архитектуры и функций с внутренними проектами (`SpoNewsMulti`, `OpsInbox`, `BaraholkaRadar`).
- Быстрое заимствование проверенных практик (источники, фильтрация, алерты, эксплуатация).
- Тестирование интеграций перед внедрением в прод-проекты.

## Важно
- Базовый upstream: `https://github.com/sansan0/TrendRadar`.
- При доработках в форке рекомендуется регулярно синхронизировать изменения с upstream.
